# flame

写真に、撮影情報を添えたフレームを合成するアプリ。

スマートフォンのブラウザで動く Web アプリ（PWA）として作っています。
**写真は端末の外に出ません。** EXIF の読み取りから画像の書き出しまで、すべてブラウザの中で完結します。
