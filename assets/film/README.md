# 仕上がりの札（フィルムシミュレーションの原画）

ここの `.webp` は**このアプリの持ち主から支給されたもの**で、富士フイルム株式会社の
製品名・商標を含む。作り直したものではない。

- 差し替え・追加は、この場所に `<名前>.webp` を置いて `npm run assets:film` を実行する。
- **ファイル名がそのまま EXIF から読み取る名前**（`app/fuji.ts` が返す文字列）になる。
  `CLASSIC Neg.` のように空白と点を含む名前も、そのままの綴りで置く。
- 配布物（`public/film/`）へは URL に出せる名前に直して複製し、対応は
  `public/film/manifest.json` に書き出す。コードにファイル名は直書きしない。
- 札を持たない名前（`MONOCHROME` / `BLEACH BYPASS` や他社の呼び名）は、
  画面では「名前だけの札」に落ちる。足したければここに置けばよい。
