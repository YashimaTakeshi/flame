写真に、
撮影情報の縁取りを。

カメラ・レンズ・露出・撮影日を写真から読み取り、余白と文字を整えて書き出します。ブラウザで開くだけ、インストールも登録も要りません。

アプリを開く 無料・登録不要
Works

同じ写真でも、額が変わると見え方が変わる

比率・余白・地色・書体を選ぶだけ。文字の大きさや位置は、写真の大きさに合わせて自動で整います。

作例の画像はイメージです（写真の代わりに描いた絵を、Fuchidori で縁取りしたもの）。撮影情報も作例用の値です。

Features

整えるための道具を、必要なだけ

細かく作り込むこともできますが、写真を選んだ時点で、そのまま出せる形に整っています。

  • 01

    撮影情報を自動で

    カメラ・レンズ・F値・シャッター速度・ISO・焦点距離・撮影日を写真から読み取ります。富士フイルムのフィルムシミュレーション名にも対応。記録が無い項目は手で入力できます。

  • 02

    SNS の比率にそのまま

    元の比率のほか、4:5・3:4・2:3・1:1・9:16・16:9・1.91:1。Instagram・X・Threads・TikTok に投稿する形で書き出せます。

  • 03

    余白・地色・枠線

    余白は「なし」から「広い」までの5段。「なし」なら写真の上に文字を重ねます。地色は9色、写真の枠線は5段。

  • 04

    14種類の書体

    Helvetica・Futura・DIN・Didot 風などの欧文書体（太字を含む）と日本語の書体。字の大きさと字間も選べます。

  • 05

    文字の並びを自由に

    1〜4行。どの情報を何行目に出すかはドラッグで入れ替え。区切り文字（, · / — | 空白）や日付の書き方も選べます。

  • 06

    動画にも同じ縁取り

    60秒までの動画にも、写真と同じ額と文字を付けて書き出せます（ブラウザが動画の書き出しに対応している場合）。

写真は、端末の外に出ません

読み込みから書き出しまで、すべてお使いの端末のブラウザの中で処理します。

プライバシーポリシー

  • アップロードしません。 写真や動画をサーバーに送る仕組みがありません。
  • アクセス解析・広告を入れていません。 Cookie も使いません。
  • 位置情報を取り除いて書き出します。 撮影情報（EXIF）は残し、GPS だけを消します。
  • 設定はこの端末にだけ残ります。 次に開いたとき、前回の額から始められます。
How to

使い方は3つだけ

  1. 写真を選ぶ

    真ん中の枠を押して写真か動画を選びます。パソコンならドラッグ＆ドロップや貼り付けでも。

  2. 整える

    比率・余白・文字・書体を選びます。下のタブを切り替えながら、仕上がりを見て決められます。

  3. 保存・共有

    iPhone は共有シートから「画像を保存」やそのまま SNS へ。パソコンは保存先を選んでダウンロード。

Install

ホーム画面に置くと、アプリのように使えます

App Store からのインストールは要りません。ホーム画面のアイコンから、ブラウザの枠なしで開けます。

iPhone・iPad（Safari）

  1. Safari でアプリを開く
  2. 下の共有ボタン（□に↑）を押す
  3. 「ホーム画面に追加」を選ぶ

Android（Chrome）

  1. Chrome でアプリを開く
  2. 右上の︙メニューを押す
  3. 「ホーム画面に追加」または「アプリをインストール」を選ぶ
Specs

動作環境と書き出し

対応ブラウザ
iPhone・iPad の Safari、Android の Chrome、パソコンの Chrome・Edge・Safari（いずれも最新版を推奨）
写真
JPEG で書き出し（長辺 4096px）。撮影情報（EXIF）は残し、位置情報は消します
動画
60秒まで。MP4 で書き出し（長辺 1920px）。ブラウザによって MOV・WebM になることがあります
料金
無料。アカウント登録も要りません
