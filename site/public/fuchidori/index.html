写真に撮影情報の額をつける Web アプリ

F1.8・15秒・ISO3200あの夜の設定ごと、
額に入れる。

写真を選ぶと、カメラとレンズ、露出の記録を読み取って、余白に小さく組みます。比率と地色を決めたら、そのまま保存して投稿へ。ブラウザで動くので、インストールも登録もいりません。

アプリを開く 無料で使えます

カメラが残した記録を読んで、写真の下に3行で組む

撮影日、カメラ、レンズ、焦点距離、F値、シャッター速度、ISO。写真のファイルに入っている記録をそのまま使います。記録が無い項目は、その場で打ち込めます。

1行目撮影日　書き方は 2025.05.24／2025年5月24日 など6通り
2行目カメラ　太字で目立たせる
3行目レンズ・焦点距離・F値・シャッター速度・ISO

富士フイルムの写真は、フィルムシミュレーション名（CLASSIC CHROME など）も読み取ります。どの項目を何行目に出すかはドラッグで入れ替えられ、行数は1〜4行から選べます。

撮って出しの一枚が、額に入るとこうなる

同じ写真でも、額を替えると印象が変わる

比率は8種類、地色は9色、書体は14種類。余白を「なし」にすると、文字を写真の上に重ねます。

投稿先の形に合わせて、そのまま書き出す

ほかに、元の比率・3:4・2:3・1.91:1。

写真は、どこにも送りません

読み込みから書き出しまで、お使いのスマホやパソコンのブラウザの中で処理します。Fuchidori のサーバーには、写真を受け取る仕組みがありません。

選んで、整えて、保存する

  1. 1写真を選ぶ

    まん中の枠を押して、写真か動画を選びます。パソコンなら、ドラッグや貼り付けでも。

  2. 2整える

    比率・余白・地色・文字を、下のタブで切り替えながら決めます。

  3. 3保存する

    iPhone は共有シートから写真に保存。Instagram や X にもそのまま送れます。

アプリを開く

ホーム画面に追加すると、アプリのように開けます。iPhone は Safari の共有ボタンから「ホーム画面に追加」、Android は Chrome のメニューから「ホーム画面に追加」。
