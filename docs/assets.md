# 同梱アセットの作り方

出来上がった woff2 と JSON は **リポジトリにコミットしてある**。
通常のビルド（CI・Cloudflare）でこれらのスクリプトは走らないので、Python も 52MB の
ダウンロードも要らない。書体や地名データを差し替えるときだけ手元で走らせる。

| 作るもの | コマンド | 必要なもの |
|---|---|---|
| フォント | `npm run assets:fonts` | Python 3 ＋ `pip install fonttools brotli` |
| 地名データ | `npm run assets:geo` | Node のみ（52MB を取得する） |
| **検査** | `npm run assets:verify` | Node のみ。**`npm run build` の先頭で必ず走る** |

## フォント（`scripts/build-fonts.py`）

欧文8書体は Google Fonts（OFL 1.1）から取得してラテン範囲にサブセットする。
和文は Noto Sans JP を JIS X 0208 第一水準＋異体字にサブセットする。
文字集合は **JIS の区点を ISO-2022-JP でデコードして起こす**ので、外部の漢字リストに依存しない。

実測で分かっている2つの罠を、スクリプトの中で機械的に潰している。

1. **可変フォントのまま `pyftsubset` にかけると全ウェイトのデータが残る。**
   和文で 442KB → 1,043KB（2.3倍）。動作はするので気づけない。
   `fontTools.varLib.instancer` で `wght` を固定してからサブセットする。
2. **「山﨑」「髙橋」の 﨑・髙 は JIS X 0208 の外**にあり、素直にサブセットすると欠落する。
   姓として頻出するので、異体字を明示的に足し、**ビルドの最後に cmap を見て収録を確認**する。

Tinos だけ `google/fonts` に `OFL.txt` が無い（404 を実測）。本家 `googlefonts/tinos` から取る。

### ビルドは再現する

同じ入力から毎回同じバイト列が出る。成果物をコミットしている以上、再現しないと
「この woff2 は本当にこのスクリプトから出たのか」を確かめられない。

再現を壊していたのは `varLib.instancer` で、**既定でフォント内の `head.modified` を
現在時刻に書き換える**（`subset` 側は書き換えない）。実際に、2回のビルドで
タイムスタンプが 1,609 秒ぶんずれ、14ファイルのバイト列が変わった。
`--no-recalc-timestamp` を付けて止めてある。

manifest には各ファイルの **SHA-256** を記録する。検査スクリプト（Node）はこれを照合するので、
**Python が無い環境（CI・Cloudflare）でも、成果物が手で触られていないことを確かめられる**。

### 出来上がり（実測）

| | Regular | Bold |
|---|---:|---:|
| Arimo / Jost / Oswald / Cinzel | 11.5〜15.5 KB | 12.8〜16.6 KB |
| PlayfairDisplay / LibreBaskerville | 20.8〜21.0 KB | 21.9〜22.5 KB |
| PTSerif / Tinos | 14.4 KB | 14.4〜14.5 KB |
| **欧文8書体 合計** | **255.3 KB** | |

## 地名データ（`scripts/build-geo.mjs`）

逆ジオコーディング API は使わない。**GPS 座標を端末の外に出さない**ため、代表点を同梱して
最近傍で引く。

| | 件数 | サイズ | 出典 | ライセンス |
|---|---:|---:|---|---|
| 日本の市区町村 | 1,894 | 91.3 KB | Geolonia 住所データ | CC BY 4.0 |
| 世界の主要都市（人口1.5万以上） | 24,323 | 986.4 KB | GeoNames | CC BY 4.0 |

出典の表示義務があるので、`attribution` を JSON に持たせてアプリ内に表示する。

### ビルド時の検品

元データには**座標が空の行がある**。`Number('')` は 0 になるため、弾かずに平均すると
代表点が海の彼方へ引きずられる（実際に大分市が北緯30.4度・東経120.6度＝中国大陸の沖に出た）。
行単位で空欄と日本の範囲外を捨て、**出来上がりに対しても範囲と引用符の混入を検査する**。

### 精度と自信度（n=5 の検証）

代表点の最近傍なので、行政境界の付近では隣の自治体が出る。断定しないために
「**2位までの距離 ÷ 1位までの距離**」を自信度に使う。1.3 未満なら市区町村を名乗らず県に切り上げる。

| 地点 | 引けた地名 | 2位/1位 | 判定 | 正誤 |
|---|---|---:|---|---|
| 宮島（厳島神社） | 広島県 廿日市市 | 2.56 | 高 | ○ |
| 大分市役所 | 大分県 大分市 | 3.57 | 高 | ○ |
| 札幌時計台 | 北海道 札幌市中央区 | 2.43 | 高 | ○ |
| 東京駅 | 東京都 中央区 | 1.24 | 低→県に上げる | ×（正解は千代田区） |
| 那覇空港 | 沖縄県 豊見城市 | 1.24 | 低→県に上げる | ×（正解は那覇市） |

**誤答2件を両方とも低自信度として検出し、正答3件はすべて高自信度**だった。
ただし n=5 の小標本であり、閾値 1.3 は実装後に事例を増やして見直す。

## 検査（`scripts/verify-assets.mjs`）

`npm run build` の先頭で走る。サイズの上限、manifest との一致、和文の収録文字数、
和文 Bold が紛れ込んでいないこと、ライセンス本文が揃っていることを見る。
上の2つの罠はどちらもサイズに現れるので、上限を超えたらビルドを止める。
