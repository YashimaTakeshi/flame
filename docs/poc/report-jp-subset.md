# 追加実測: 和文サブセットのサイズ

測定日: 2026-09-21 / fonttools 4.65 + brotli / Noto Sans JP（可変フォント原本 9,589,900 B）
再現スクリプト: `scratchpad/jis_sets.py`（JIS X 0208 の区点からオフラインで文字集合を生成）

要件 §7 で「常用漢字＋かな＋記号の固定サブセットを同梱」と決めたが、その実サイズが未実測だった。
数百KBで収まるか1MBを超えるかで方式の現実味が変わるため、実際に作って測った。

## 文字集合の作り方

外部データに頼らず、**JIS X 0208 の区点を ISO-2022-JP でデコードして**集合を構成した
（ネットワーク不要・完全に再現可能）。

| 集合 | 内容 | 文字数 |
|---|---|---:|
| core | ASCII ＋ 記号 ＋ 全角英数 ＋ ひらがな・カタカナ ＋ 約物 | 478 |
| lv1 | core ＋ **第一水準漢字 2,965字** | 3,443 |
| lv1p | lv1 ＋ 人名・地名の異体字38字（﨑 髙 德 濵 齋 邊 …） | 3,481 |
| lv12 | lv1 ＋ 第二水準漢字 3,390字 | 6,833 |

## 実測サイズ（woff2、wght を固定した静的フォント）

**重要**: 可変フォントのままサブセットすると全ウェイト分のデータが残り、lv1 で **1,043KB** になる。
`fontTools.varLib.instancer` で wght を固定してからサブセットすると **459KB** に落ちる（**2.3倍の差**）。

| 集合 | Regular(400) | Bold(700) | 両方 |
|---|---:|---:|---:|
| core（漢字なし） | 57.3 KB | 59.3 KB | 116.6 KB |
| **lv1p（採用候補）** | **462.9 KB** | **473.1 KB** | **936.0 KB** |
| lv12（第二水準まで） | 949.7 KB | 971.0 KB | 1,920.7 KB |

## 収録の検証

lv1p サブセットの収録グリフ数 **3,480**。`getBestCmap()` で実際に確認:

- 「夕焼けの街並みにて撮影」「富士フイルム」「広島県廿日市市」「2026年9月20日」 … すべて収録
- **﨑(U+FA11)・髙(U+9AD9)** … 収録（「山﨑」「髙橋」が化けない。これらは JIS X 0208 外なので
  明示的に足さないと欠落する。姓として頻出するため実害が大きい）
- 々・〆・〇 … 収録
- 欠落したのは ㊙ のような囲み記号のみ

## 方針への反映

1. **和文フォントは初回ロードに含めない。** 日本語書体を選んだ時点で遅延ロードする。
   欧文だけで使う人には 1KB も転送しない。
2. **同梱するのは lv1p。** 第二水準まで入れると倍以上になるわりに、増える3,390字は
   日常のキャプションでまず使わない。
3. **必ず wght を固定してからサブセットする。** 可変のままだと 2.3倍になる。
4. **Bold を入れるかは設計で判断する。** Regular だけなら 463KB、Bold を足すと 936KB。
   キャプションの階層を「太さ」でなく「色の濃淡とサイズ」で表現すれば Regular だけで済む。
5. lv1p にも無い文字（第二水準の稀な漢字など）が入力されたときだけ、
   確認のうえ Google Fonts から取得する（実測 9.2KB）。

## 転送量の全体像

| 場面 | 追加転送 |
|---|---:|
| 初回ロード（欧文8書体すべて） | 237.3 KB |
| 初回ロード（既定書体1つだけ・書体選択を開くまで遅延） | 20.5 KB |
| 日本語書体を選んだとき（Regular のみ） | +462.9 KB |
| 日本語書体を選んだとき（Regular + Bold） | +936.0 KB |
| 撮影地を有効にしたとき（日本のみ） | +33 KB |
| 撮影地を有効にしたとき（世界の主要都市を含む） | +503 KB |

いずれも1回きりで、以降はキャッシュから読む。
